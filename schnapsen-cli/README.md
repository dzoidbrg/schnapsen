# schnapsen-cli

Terminal UI for playing Dreierschnapsen, built with [ratatui](https://ratatui.rs/).

## Run

```bash
cargo run -p schnapsen-cli
```

## Controls

- **← / →** — Select card in hand
- **Enter** — Play selected card
- **Space** — AI plays (when it's the AI's turn)
- **q / Esc** — Quit
